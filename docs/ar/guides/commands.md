## 1. أرشيف المحادثات والبحث الفوري

| الأمر | الوصف |
|---|---|
| `!chats [page]` | قائمة مرقّمة بكل المحادثات عبر سطح المكتب و`agy CLI` مرتّبة زمنياً. |
| `!cli-chats` | عرض الجلسات المُنشأة أصلاً من سطر الأوامر. |
| `!archived` | عرض المحادثات المؤرشفة. |
| `!search <query>` | بحث نصي كامل (`SQLite FTS5` + `RPC`) في عناوين الجلسات والأسئلة والردود مع إظهار مقتطفات وأرقام الجلسات. |
| `!read <num\|id> [all\|N]` | فتح أي جلسة سابقة في خيط مخصّص على ديسكورد وإرفاق نص المحادثة الكامل بصيغة `Markdown`. |
| `!archive` / `!unarchive` | أرشفة الجلسة أو إلغاء أرشفتها في الاتجاهين بين ديسكورد و`Antigravity Desktop`. |

## 2. التحكم في الجلسات وواجهة سطح المكتب

| الأمر | الوصف |
|---|---|
| `!sessions` / `!running` | لوحة حية لحالة تطبيق سطح المكتب وخادم اللغة وعمليات `agy` الشغّالة حالياً. |
| `!open` | تشغيل واجهة `Antigravity Desktop` على الشاشة الرسومية `:0` إذا كانت مغلقة. |
| `!stop [num\|id]` / `!cancel` | إلغاء فوري لأي استدعاء شلال عالق (`CancelCascadeInvocation`) أو مهمة خلفية. |

## 3. قياسات المحطة والطرفية المباشرة

| الأمر | الوصف |
|---|---|
| `!status` | تقرير شامل للعتاد: حمل المعالج، الذاكرة و`Swap`، مستشعرات الحرارة، البطارية، القرص، وتقدّم خدمات النظام. |
| `!jobs` / `!crop` | متابعة حالة الخدمات الخلفية ومهام المعالجة المستمرة. |
| `!sh <command>` | تنفيذ أمر `bash` مباشر على المحطة وإرجاع المخرجات (`stdout/stderr`) منسّقة للقراءة على الهاتف. |
| `!help` | إرسال بطاقة الأوامر المختصرة باللغة المطابقة لسؤالك. |
